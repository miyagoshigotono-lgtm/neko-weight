# ご飯アゲアゲ君

猫用自動給餌器。**弾倉式スクリューコンベア**方式。

太った猫（8kg台）の減量が目的。床置きの餌を食べ放題にさせないため、猫を識別する代わりに「1日分をあらかじめ小分けし、機械が時間差で出す」方式を採る。

- 水平パイプ内の一条スクリューの**各ピッチを1回分の小部屋（弾倉）**として使う
- 1回の給餌＝**スクリュー1回転**＝全部屋が1ピッチ前進＝末尾の部屋の中身が餌皿へ落下
- ホッパーを持たず、毎朝の手作業で各部屋に小分けするため**吐出量の校正が不要**
- 1日9回。制御は Digispark（ATtiny85）、装填完了ボタンの押下時刻を起点とした相対計時

詳細は **[SPEC.md](SPEC.md)** を参照。
